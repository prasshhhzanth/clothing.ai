# Clothing.ai 👕✨

Clothing.ai is an intelligent fashion assistant designed to bridge the gap between imagination and reality. It helps users generate unique clothing designs, find matching items online through direct shopping links, and experience fashion in a new dimension using AR (Augmented Reality) camera integration.

## 🚀 Features

- **AI-Driven Design Generation:** Create unique fashion designs and patterns using advanced AI models.
- **Smart Product Discovery:** Automatically find and provide purchase links for clothing items available across online marketplaces.
- **AR Virtual Try-On (In Progress):** Use your device's camera to visualize how designs look on you in real-time.
- **Developer Friendly:** Built with a modular Python backend for easy integration and scaling.

## 🛠️ Tech Stack

- **Backend:** Python (Flask/FastAPI)
- **AI/ML:** Integration with Generative AI models for design creation.
- **Frontend/UI:** Interactive web interface for seamless user experience.
- **AR Integration:** Computer Vision and AR libraries for camera-based visualization.
- **Environment Management:** Python-dotenv for secure API key handling.

## ⚙️ Installation & Setup

1. **Clone the repository:**
```bash
git clone [https://github.com/prasshhhzanth/clothing.ai.git](https://github.com/prasshhhzanth/clothing.ai.git)
cd clothing.ai

```


2. **Create a virtual environment:**
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

```


3. **Install dependencies:**
```bash
pip install -r requirements.txt

```


4. **Environment Variables:**
Create a `.env` file in the root directory and add your necessary API credentials (e.g., OpenAI, Stability AI, or Shopping APIs).
5. **Run the application:**
```bash
python app.py

```
